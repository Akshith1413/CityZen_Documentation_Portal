ACTUAL CAPTURES AND ILLUSTRATIONS
The four primary admin PNGs and video poster are actual captures of CityZen running at localhost:5173 using the authorized account. They are not AI-generated interfaces. They preserve the available build. Their source data was not changed for this pack.
The hero, validation pothole and wider companion view were generated using the built-in image generation tool. The same generated pothole reference is used in Observation, Validation, Geometry, and gallery FIG 04-05. Hero is a separate street photo.
Observation is a project-styled demonstration report using the generated incident, not an actual submitted report. Submission Flow is a diagram of four phone screens reconstructed using the project's monochrome design, category names and location privacy options, not a native Expo capture. These were necessary to keep the same generated incident across the website story.
The mask is an illustrative generated segmentation silhouette, cleaned and composited onto the exact original photo crop at #8E123A / 40% opacity, with an outline. It is not a model inference or validation claim. Geometry values (1.2 m, 0.8 m, 0.96 m², shallow depth) reproduce the brief's demonstration, not physical measurements inferred from a photograph. AHP uses the brief's 43/33/14/10 weights; illustrative inputs 92/86/80/70 yield 86.14/100. Architecture follows the five requested layers.

RUNNING BUILD DIFFERENCES
1. The raw inbox already displays severity scores. It remains unfiltered and in arrival order.
2. The queue has four tiers (Critical, Elevated/High, Moderate, Routine/Low), not the brief's five bands ending in Minimal.
3. The map shows status markers, not a calculated heat layer. Several Chennai reports overlap at one location; some other records use zero coordinates. The capture is framed on the populated Chennai location.
4. The detail UI uses status controls instead of three named stage tabs. Explain AI returned: 'Requested Roboflow resource not found.' A broken AI dialog is not included as a finished asset.
For the narrative requested by the document, optional/presentation contains four clearly identified alternatives: an unranked demo inbox collage, actual queue plus five-band legend, actual map plus illustrative density overlay, and actual dossier plus an illustrative Assessment panel. These are presentation composites, not evidence that the live build implements those features. Use them only when that presentation treatment suits your page.
