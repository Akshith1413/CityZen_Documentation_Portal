## 📖 Overview

CityZen is an advanced, cinematic web documentation portal built to showcase an AI-powered civic intelligence architecture. It provides an immersive, forensic-style deep dive into the engineering, architecture, and deployment of a multi-platform system designed to streamline urban incident reporting and resolution.

This repository houses the **Interactive Documentation Portal**, featuring cutting-edge scroll-driven 3D animations and interactive UI components.

## ✨ Features

- **Cinematic Experience**: Immersive, full-viewport scroll-driven narratives.
- **Forensic UI/UX**: A crisp, aesthetic design system reminiscent of technical dossiers and data visualization.
- **Advanced GSAP Animations**: 
  - Dynamic 3D card dealing architectures.
  - Interactive mouse-tracking parallax shapes and liquid border morphs.
  - Seamless layout morphs and scroll-scrubbed timelines.
- **Fully Responsive**: Adapts flawlessly from mobile displays to ultrawide desktop monitors.

## 🛠️ Tech Stack

- **Core**: [React 18](https://react.dev/), [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS (Advanced CSS Variables, Flexbox/Grid, Transform 3D)
- **Animation**: [GSAP](https://gsap.com/) (GreenSock Animation Platform) + ScrollTrigger
- **Typography**: *Space Grotesk* (Display), *IBM Plex Mono* (Technical), *Source Serif 4* (Body)

## 🚀 Getting Started

To run the documentation portal locally:

### 1. Clone the repository
```bash
git clone https://github.com/Akshith1413/CityZen_Documentation_Portal.git
cd CityZen_Documentation_Portal
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```

The portal will be available at `http://localhost:5173`.
